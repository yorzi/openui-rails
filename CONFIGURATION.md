# Configuration

Use the [configuration guide](https://openui-rails.wangyaodi.com/configuration/)
for settings, defaults, and the shared idempotency-store contract.
Review [production setup](https://openui-rails.wangyaodi.com/production/)
before deploying.

The site documents the latest release. For `main`, use
[/next/configuration/](https://openui-rails.wangyaodi.com/next/configuration/).
To read offline, open the [guide source](docs/_getting_started/configuration.md)
at the tag matching your installed gem.
