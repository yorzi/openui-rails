# Upgrading

Read the [upgrade guide](https://openui-rails.wangyaodi.com/upgrading/)
for migration steps and the [changelog](CHANGELOG.md) for release changes.

The site documents the latest release. For `main`, use
[/next/upgrading/](https://openui-rails.wangyaodi.com/next/upgrading/).
To read offline, open the [guide source](docs/_reference/upgrading.md)
at the tag matching your installed gem.
